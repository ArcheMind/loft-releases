Public macOS installation packages for [Loft](https://loft.archemind.org/), a
spatial workspace for distributed teams.

## Download

Use the branded [Loft download page](https://loft.archemind.org/download/) or
open the [latest GitHub Release](https://github.com/ArcheMind/loft-releases/releases/latest).

Native macOS packages are distributed separately for Apple Silicon (arm64) and
Intel (x64), with a DMG installer and update ZIP for each architecture. Manual
beta builds are Developer ID signed and notarized by Apple. Choose your Mac chip
on the download page. In-app updates select the native architecture, including
arm64 on Apple Silicon running under Rosetta.

This repository intentionally contains public release automation and binary
release assets only. The Loft application source remains private.
